# TOEIC-like Full Tests - Documentation

## Overview

This directory contains 100 full TOEIC-like practice tests generated for the TOEIC-AI project. Each test contains 200 questions across 7 parts, following the standard TOEIC format.

## Directory Structure

```

│   ├── part1_images_manifest.json  # Manifest for Part 1 images
│   └── audio_manifest.json  # Manifest for audio files
├── audio/                  # Audio files (to be generated)
│   ├── test001/
│   ├── test002/
│   └── ...
├── images/                 # Part 1 images (to be generated)

│   ├── test002/

│   ├── generate_audio_manifest.py

│   ├── generate_part1_images_manifest.py
```

## Test Structure

Each test contains 200 questions distributed as follows:

| Part | Questions | Groups | Description |
|------|-----------|--------|-------------|
| 1    | 6         | 6      | Photographs |
| 2    | 25        | 25     | Question-Response |
| 3    | 39        | 13     | Conversations (3 questions per group) |
| 4    | 30        | 10     | Talks (3 questions per group) |
| 5    | 30        | 30     | Incomplete Sentences |
| 6    | 16        | 4      | Text Completion (4 questions per group) |
| 7    | 54        | 15     | Reading Comprehension |
| **Total** | **200** | **103** | |

## Database Schema

The tests are designed to work with the following Prisma schema:

- `tests` - Test metadata
- `question_groups` - Groups of questions by part
- `questions` - Individual questions
- `options` - Answer choices (A, B, C, D)
- `knowledge` field added to `question_groups` for explanations

## How to Generate Tests

### 1. Generate Test Data

```bash
# From the project root
python toeic-generated-data/scripts/generate_toeic_tests.py
```

This will generate all 100 test JSON files in `toeic-generated-data/data/tests/`.

### 2. Generate Audio Manifest

```bash
python toeic-generated-data/scripts/generate_audio_manifest.py
```

This creates `audio_manifest.json` with all audio file references and transcripts.

### 3. Generate Part 1 Images Manifest

```bash
python toeic-generated-data/scripts/generate_part1_images_manifest.py
```

This creates `part1_images_manifest.json` with 600 image prompts.

### 4. Validate Tests

```bash
python toeic-generated-data/scripts/validate_tests.py
```

This validates all tests and generates reports in the `validation/` directory.

## How to Generate Audio Files

The `generate_audio.py` script provides templates for TTS integration. To use it:

1. Install a TTS library:
   ```bash
   pip install gtts  # Google TTS
   # or
   pip install edge-tts  # Microsoft Edge TTS
   ```

2. Uncomment the TTS implementation in `scripts/generate_audio.py`

3. Run the script:
   ```bash
   python toeic-generated-data/scripts/generate_audio.py
   ```

The script will create MP3 files in the `audio/` directory structure.

## How to Generate Part 1 Images

The `generate_part1_images.py` script provides templates for AI image generation. To use it:

1. Set up an AI image generation service:
   - OpenAI DALL-E API
   - Stable Diffusion (local)
   - Replicate API

2. Add your API key or configure the local model in the script

3. Uncomment the AI implementation in `scripts/generate_part1_images.py`

4. Run the script:
   ```bash
   python toeic-generated-data/scripts/generate_part1_images.py
   ```

The script will create 600 images in the `images/` directory structure.

## How to Import Tests into Database

The import script is located at `apps/api/scripts/import_full_tests.ts`.

### Import All Tests

```bash
cd apps/api
npm run ts-node scripts/import_full_tests.ts
```

### Import a Batch of Tests

```bash
cd apps/api
npm run ts-node scripts/import_full_tests.ts -- --from=1 --to=10
```

### Import Safety Features

- Each test is imported in a separate transaction
- If a test fails, only that test's transaction is rolled back
- Existing data is never deleted or modified
- IDs are auto-generated by the database

## File Naming Conventions

### Test Files
- `test001.json` through `test100.json`

### Audio Files
- `test{N}_part{P}_group{G}.mp3`
- Example: `test001_part01_group001.mp3`

### Part 1 Images
- `test{N}_part01_q{Q}.jpg`
- Example: `test001_part01_q001.jpg`

## Rollback Procedure

If you need to remove imported tests:

```sql
-- Delete specific test
DELETE FROM question_groups WHERE test_id = X;

-- Or delete a range
DELETE FROM question_groups WHERE test_id BETWEEN 1 AND 10;
```

Note: Due to foreign key constraints, deleting from `question_groups` will cascade delete related `questions` and `options`.

## Troubleshooting

### Import Fails
- Check database connection in `.env`
- Ensure Prisma client is generated: `npx prisma generate`
- Verify schema includes the `knowledge` field

### Audio Generation Fails
- Verify TTS library installation
- Check API key configuration
- Ensure output directory has write permissions

### Image Generation Fails
- Verify AI service API key
- Check account credits/limits
- Ensure output directory has write permissions
