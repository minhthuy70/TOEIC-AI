# Kế Hoạch Triển Khai & Kiểm Thử: 7.3. Test History (Lịch sử kiểm tra)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Quản lý và Phân tích Lịch Sử Kiểm Tra (Test History) cho nền tảng TOEIC-AI.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu, typography, khoảng cách (spacing), layout và card style hiện có của website mà không làm xáo trộn bất kỳ thành phần nào.

---

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Backend (`apps/api`)
- `apps/api/src/mock-test/mock-test.service.ts`:
  - `deleteAttempt(userId, attemptId)`: Xóa bản ghi `mock_test_attempts`.
- `apps/api/src/mock-test/mock-test.controller.ts`:
  - Thêm endpoint `@Delete('history/:attemptId')`.

### Frontend (`apps/web`)
- `apps/web/services/mock-test.ts`:
  - Thêm phương thức `deleteMockTestAttempt(attemptId)`.
- `apps/web/app/dashboard/mock-test/page.tsx`:
  - Tích hợp 4 thẻ thống kê tổng quan.
  - Thanh tìm kiếm và bộ lọc (Full vs Mini, khoảng ngày, khoảng điểm, sắp xếp ngày/điểm).
  - Modal xem nhanh chi tiết bài thi (Quick Detail View Modal).
  - Modal so sánh đối soát 2 bài thi (Compare Tests Modal).
  - Xuất dữ liệu CSV và JSON.
  - Modal xác nhận xóa bài thi với toast thông báo.

## 4. Kết Quả Kiểm Thử (Verification)
1. **Kiểm thử biên dịch TypeScript**:
   - `apps/api`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
   - `apps/web`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
2. **Kiểm thử chức năng**:
   - Bộ lọc và tìm kiếm hoạt động chính xác.
   - So sánh 2 bài thi hiển thị bảng chênh lệch điểm số rõ ràng.
   - Xuất file CSV / JSON thành công.
   - Xóa bài thi cập nhật danh sách và thống kê tức thì.
