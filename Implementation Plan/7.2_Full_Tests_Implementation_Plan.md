# Kế Hoạch Triển Khai & Kiểm Thử: 7.2. Full Tests (Kiểm Tra Đầy Đủ)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Kiểm Tra Đầy Đủ (Full TOEIC Test - 200 câu hỏi 120 phút) cho nền tảng TOEIC-AI.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu, typography, khoảng cách (spacing), layout và card style hiện có của website mà không làm xáo trộn bất kỳ thành phần nào.

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Backend (`apps/api`)
- `apps/api/src/mock-test/mock-test.service.ts`:
  - `startCustomFullTest(userId, dto)`: Hỗ trợ tạo đề thi Full Test chuẩn 200 câu hoặc Custom theo part/số câu.
  - `getTestResult(attemptId)`: Mở rộng tính toán Percentile ranking, transcript, evidence highlighting, và so sánh hiệu suất.
- `apps/api/src/mock-test/mock-test.controller.ts`:
  - `POST /mock-test/custom-test/start`

### Frontend (`apps/web`)
- `apps/web/services/mock-test.ts`:
  - Client method `startCustomFullTest()` và các types `percentileRanking`, `performanceComparison`, `transcript`, `evidence`.
- `apps/web/app/dashboard/mock-test/page.tsx`:
  - Thêm modal Cấu hình bài thi Full Test (Tiêu chuẩn / Tùy chỉnh parts & thời gian) và nút mở Modal Hướng dẫn.
- `apps/web/app/dashboard/mock-test/[attemptId]/page.tsx`:
  - Thêm Section Break Notification (1–2 phút), Nút bắt đầu Reading, Đồng hồ phần & tổng thể, Tạm dừng giới hạn 3 lần, Gắn cờ 🚩, Nộp phần và Modal xác nhận nộp bài.
- `apps/web/app/dashboard/mock-test/result/[attemptId]/page.tsx`:
  - Thêm Bảng điểm TOEIC 990, Percentile ranking, Performance comparison, Lời giải kèm Transcript & Evidence Highlight, Lưu sổ tay lỗi ⭐, Làm lại đề 🔄, Chia sẻ kết quả 🔗, In ấn / Tải PDF 🖨️.

## 4. Kết Quả Kiểm Thử (Verification)
1. **Kiểm thử biên dịch TypeScript**:
   - `apps/api`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
   - `apps/web`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
2. **Kiểm thử quy trình Full Test**:
   - Cấu hình đề (Standard / Custom) -> Mở modal hướng dẫn -> Bắt đầu thi -> Đồng hồ phần & tổng -> Tạm dừng (giới hạn 3 lần) -> Hoàn thành Listening -> Section break notification -> Nút bắt đầu Reading -> Đánh dấu cờ -> Nộp bài -> Bảng điểm, Percentile ranking, so sánh hiệu suất, Transcript, Evidence highlight, Lưu sổ tay lỗi ⭐, In/Tải PDF 🖨️.
3. **Bảo toàn thiết kế**: Giữ nguyên 100% style dark mode và component hệ thống hiện có.
