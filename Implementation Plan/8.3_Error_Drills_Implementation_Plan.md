# Kế Hoạch Triển Khai & Kiểm Thử: 8.3. Error Drills (Bài Tập Lỗi)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Luyện Tập Câu Sai Thông Minh (Error Drills & Spaced Repetition) cho nền tảng TOEIC-AI.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu dark theme, typography, khoảng cách (spacing), layout, modals, dropdowns, Web Audio API sound feedback và card style hiện có của website mà không làm xáo trộn bất kỳ thành phần nào.

---

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Backend (`apps/api`)
- `apps/api/src/error-tracking/error-tracking.service.ts`:
  - `generateDrill`: Tạo bộ đề Drill từ `error_logs` dựa theo mode (top10, type, all) và giới hạn số câu.
  - `submitDrill`: Chấm bài, tự động auto-resolve câu đúng, tăng tần suất câu sai và tính tỷ lệ thành công.
  - `scheduleDrill`: Xử lý đặt lịch nhắc nhở sau X ngày.
- `apps/api/src/error-tracking/error-tracking.controller.ts`:
  - `POST /error-log/drill/generate`, `POST /error-log/drill/submit`, `POST /error-log/drill/schedule`.

### Frontend (`apps/web`)
- `apps/web/services/error-tracking.ts`:
  - Thêm `generateErrorDrill()`, `submitErrorDrill()`, `scheduleRepeatDrill()` và các interface tương ứng.
- `apps/web/app/dashboard/error-log/page.tsx`:
  - Tích hợp Tab `⚡ Luyện tập Drill (8.3)` với quy trình 3 bước hoàn chỉnh:
    1. Thiết lập cấu hình Drill
    2. Trình làm bài tương tác có phản hồi tức thì và âm thanh Web Audio
    3. Màn hình tổng kết với tỷ lệ thành công, câu đã tự động giải quyết và lên lịch Spaced Repetition.

## 4. Kết Quả Kiểm Thử (Verification)
1. **Kiểm thử biên dịch TypeScript**:
   - `apps/api`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
   - `apps/web`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
2. **Kiểm thử chức năng**:
   - Khởi tạo drill theo Top 10 câu sai / theo loại lỗi mượt mà.
   - Trình làm bài drill hiển thị đồng hồ đếm thời gian, thanh tiến độ, chọn đáp án hiển thị phản hồi tức thì kèm âm thanh.
   - Hoàn thành drill: hiển thị màn hình tổng kết tỷ lệ thành công, tự động chuyển câu đúng sang "Đã giải quyết".
   - Lên lịch ôn tập sau 1 / 3 / 7 ngày hoạt động chính xác kèm thông báo Toast.
