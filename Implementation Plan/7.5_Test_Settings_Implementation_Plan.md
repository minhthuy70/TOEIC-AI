# Kế Hoạch Triển Khai & Kiểm Thử: 7.5. Test Settings (Cài Đặt Kiểm Tra)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Quản lý và Tùy chỉnh Cài Đặt Kiểm Tra (Test Settings) cho nền tảng TOEIC-AI.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu, typography, khoảng cách (spacing), layout và switch style hiện có của website (`/dashboard/grammar/settings`, `/dashboard/reading/settings`) mà không làm xáo trộn bất kỳ thành phần nào.

---

## 2. Chi Tiết Các Tính Năng 7.5 Đã Triển Khai

| STT | Tính Năng | Mô Tả Thực Hiện | Trạng Thái |
| :--- | :--- | :--- | :---: |
| 1 | **Default test type** | Tùy chọn cấu hình loại bài thi mặc định: Full TOEIC Test (200 câu) hoặc Mini Test (50 câu). | [x] Hoàn thành |
| 2 | **Default time limit** | Cài đặt giới hạn thời gian mặc định: 120 phút (Chuẩn đề thi thật), 90 phút, 60 phút, 45 phút, 30 phút. | [x] Hoàn thành |
| 3 | **Show timer preference** | Bật / tắt hiển thị đồng hồ đếm ngược trong giao diện thi (giúp giảm áp lực tâm lý nếu muốn). | [x] Hoàn thành |
| 4 | **Allow pause preference** | Bật / tắt tính năng cho phép tạm dừng bài thi (tối đa 3 lần hoặc chế độ thi kỷ luật nghiêm ngặt). | [x] Hoàn thành |
| 5 | **Show real-time score preference** | Bật / tắt hiển thị tiến độ thời gian thực và ước lượng điểm số khi đang làm bài. | [x] Hoàn thành |
| 6 | **Auto-submit preference** | Bật / tắt tính năng tự động nộp bài và khóa đề ngay khi đồng hồ về 00:00. | [x] Hoàn thành |
| 7 | **Sound effects toggle** | Bật / tắt hiệu ứng âm thanh Web Audio API (Tick nhịp, Cảnh báo 1 phút cuối, Âm thanh nộp bài & hoàn thành) kèm 3 nút nghe thử. | [x] Hoàn thành |

---

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Frontend Web (`apps/web`)
- `apps/web/lib/test-settings.ts`:
  - Định nghĩa interface `TestSettings` với 7 thuộc tính.
  - `DEFAULT_TEST_SETTINGS`
  - `loadTestSettings()`, `saveTestSettings()` qua `localStorage` (`toeic_test_settings`).
  - Hệ thống âm thanh Web Audio API độc lập `playTestSoundEffect(type)`.
- `apps/web/hooks/useTestSettings.ts`:
  - React hook quản lý state cài đặt và đồng bộ LocalStorage tức thì.
- `apps/web/app/dashboard/mock-test/settings/page.tsx`:
  - Giao diện Cài Đặt Kiểm Tra hoàn chỉnh với 7 khối cấu hình tương ứng 7 tính năng.
  - Nút kiểm tra âm thanh trực tiếp (Tick ⏱️, Cảnh báo ⚠️, Hoàn thành 🎉).
  - Nút Lưu cài đặt và Khôi phục cài đặt gốc.
- `apps/web/app/dashboard/mock-test/page.tsx`:
  - Thêm nút liên kết `⚙️ Cài đặt thi thử` trên thanh tiêu đề đầu trang.
- `apps/web/app/dashboard/mock-test/[attemptId]/page.tsx`:
  - Đọc `testSettings` để áp dụng: Tự động cảnh báo âm thanh khi còn 1 phút cuối, phát âm thanh khi nộp bài, và kiểm tra cờ `autoSubmit`.
