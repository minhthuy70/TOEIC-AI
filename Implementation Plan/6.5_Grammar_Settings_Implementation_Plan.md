# Kế Hoạch Triển Khai & Kiểm Thử: 6.5. Grammar Settings (Cài Đặt Ngữ Pháp)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Cài Đặt Cá Nhân Hóa Học & Luyện Tập Ngữ Pháp (Grammar Settings) cho nền tảng TOEIC-AI.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu, typography, khoảng cách (spacing), layout và card style hiện có của website mà không làm xáo trộn bất kỳ thành phần nào.

---

## 2. Chi Tiết Các Tính Năng 6.5 Đã Triển Khai

| STT | Tính Năng | Mô Tả Thực Hiện | Trạng Thái |
| :--- | :--- | :--- | :---: |
| 1 | **Exercise difficulty preference** | Tùy chọn độ khó bài tập mặc định khi bắt đầu luyện tập (Tất cả / Cơ bản / Trung cấp / Nâng cao). | [x] Hoàn thành |
| 2 | **Show explanations by default** | Tùy chọn tự động hiển thị/mở rộng toàn bộ giải thích chi tiết câu hỏi ngay khi xem kết quả bài làm. | [x] Hoàn thành |
| 3 | **Auto-advance after correct answer** | Tùy chọn tự động chuyển sang câu hỏi tiếp theo ngay sau khi chọn đáp án đúng. | [x] Hoàn thành |
| 4 | **Sound effects toggle** | Tùy chọn bật/tắt âm thanh phản hồi (Sound Effects) khi thao tác chọn đáp án, nộp bài hoàn thành bằng Web Audio API. | [x] Hoàn thành |

---

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Backend (`apps/api`)
- `apps/api/src/grammar/grammar.service.ts`:
  - `getGrammarSettings(userId)` & `updateGrammarSettings(userId, dto)`: Hỗ trợ lưu trữ cấu hình người dùng.
- `apps/api/src/grammar/grammar.controller.ts`:
  - `GET /grammar/settings`
  - `POST /grammar/settings`

### Frontend (`apps/web`)
- `apps/web/lib/grammar-settings.ts`:
  - `GrammarSettings`, `DEFAULT_GRAMMAR_SETTINGS`, `loadGrammarSettings()`, `saveGrammarSettings()`, `playSoundFeedback(type)`.
- `apps/web/hooks/useGrammarSettings.ts`:
  - Custom React Hook quản lý trạng thái settings với lưu trữ đồng bộ `localStorage` & API.
- `apps/web/app/dashboard/grammar/settings/page.tsx`:
  - Giao diện cài đặt ngữ pháp với đầy đủ 4 khối cài đặt, nút nghe thử âm thanh, khôi phục cài đặt gốc và lưu cài đặt.
- `apps/web/app/dashboard/grammar/exercises/page.tsx`:
  - Tích hợp `grammar-settings`: Áp dụng độ khó ưa thích khi mở trang, tự động phát âm thanh khi click/nộp bài nếu bật sound effects, tự động chuyển câu nếu bật auto-advance.
- `apps/web/app/dashboard/grammar/page.tsx`:
  - Bổ sung nút liên kết nhanh "⚙️ Cài đặt".

## 4. Kết Quả Kiểm Thử (Verification)
1. **Kiểm thử biên dịch TypeScript**:
   - `apps/api`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
   - `apps/web`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
2. **Kiểm thử tính năng cài đặt**:
   - Độ khó bài tập ưa thích áp dụng chính xác cho màn hình luyện bài tập.
   - Tự động chuyển câu (Auto-advance) hoạt động mượt mà.
   - Hiệu ứng âm thanh (Sound effects) tổng hợp qua Web Audio API phát chính xác cho từng hành động.
3. **Bảo toàn thiết kế**: Giữ nguyên 100% style dark mode và component hệ thống hiện có.
