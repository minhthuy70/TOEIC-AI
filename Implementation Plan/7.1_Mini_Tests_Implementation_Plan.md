# Kế Hoạch Triển Khai & Kiểm Thử: 7.1. Mini Tests (Kiểm Tra Nhỏ)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Kiểm Tra Nhỏ (Mini Test - 50 câu hỏi) cho nền tảng luyện thi TOEIC 900+.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu, typography, khoảng cách (spacing), layout và card style hiện có của website mà không làm xáo trộn bất kỳ thành phần nào.

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Backend (`apps/api`)
- `apps/api/src/mock-test/mock-test.service.ts`:
  - `startMiniTest(userId, dto)`: Tạo đề thi Mini Test 50 câu cân đối giữa các Part đã chọn từ ngân hàng đề thi.
  - `submitMiniTest(userId, dto)`: Chấm điểm bài thi mini test, quy đổi điểm TOEIC, phân tích thời gian từng phần và độ chính xác.
- `apps/api/src/mock-test/mock-test.controller.ts`:
  - `POST /mock-test/mini-test/start`
  - `POST /mock-test/mini-test/submit`

### Frontend (`apps/web`)
- `apps/web/services/mock-test.ts`:
  - Khai báo types và API client: `MiniTestQuestion`, `MiniTestStartResponse`, `MiniTestSubmitResponse`, `startMiniTest()`, `submitMiniTest()`.
- `apps/web/app/dashboard/mock-test/mini-test/page.tsx`:
  - Xây dựng đầy đủ 3 màn hình hoàn chỉnh:
    1. **Màn hình Cấu hình & Hướng dẫn**: Chọn Parts, chọn thời gian (30/45/60p), Modal hướng dẫn quy chế thi.
    2. **Màn hình Làm bài thi**: Timer đếm ngược, Nút Tạm dừng/Tiếp tục (Pause/Resume), Question Grid Palette, Gắn cờ 🚩, Thanh tiến độ, Real-time score indicator, Modal xác nhận nộp bài, Tự động nộp khi hết giờ.
    3. **Màn hình Kết quả & Phân tích chuyên sâu**: Thẻ điểm TOEIC (Listening, Reading, Tổng), Phân tích điểm theo Part, Phân tích thời gian, Xem lại câu sai/đúng, Lời giải chi tiết, Lưu vào sổ tay lỗi ⭐, Làm lại đề 🔄, Chia sẻ kết quả 🔗.
- `apps/web/app/dashboard/mock-test/page.tsx`:
  - Bổ sung thẻ banner khởi động nhanh "⚡ TOEIC Mini Test (50 Câu)".

## 4. Kết Quả Kiểm Thử (Verification)
1. **Kiểm thử biên dịch TypeScript**:
   - `apps/api`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
   - `apps/web`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
2. **Kiểm thử quy trình thi Mini Test**:
   - Chọn Part & Thời gian -> Mở Modal hướng dẫn -> Bắt đầu thi -> Bấm giờ -> Tạm dừng / Tiếp tục -> Nhảy câu hỏi -> Gắn cờ 🚩 -> Nộp bài -> Modal xác nhận -> Xem kết quả, phân tích thời gian & độ chính xác -> Lưu sổ tay lỗi -> Làm lại đề.
3. **Bảo toàn thiết kế**: Giữ nguyên 100% style dark mode và component hệ thống hiện có.
