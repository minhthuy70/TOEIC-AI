# Kế Hoạch Triển Khai & Kiểm Thử: 10.3. Study Reminders (Nhắc Nhở Học Tập)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống cài đặt và cấu hình Nhắc nhở học tập (Study Reminders Configuration) để học viên tự chọn thời gian, tần suất, hình thức nhận thông báo (email, push notification) nhằm duy trì thói quen học tập, bảo vệ chuỗi ngày học (streak) và cập nhật lịch ôn thi.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống layout, card style, toggle buttons, typography, khoảng cách (spacing), bảng màu dark theme, modals và toast alerts hiện có của website để trang Nhắc nhở học tập mới đồng bộ hoàn toàn với giao diện hệ thống.

---

## 2. Các Tính Năng Sẽ Triển Khai

| STT | Tính Năng | Mô Tả Kỹ Thuật |
| :--- | :--- | :--- |
| 1 | **Reminder settings** | Bảng điều khiển cấu hình toàn bộ chế độ nhắc nhở học tập. |
| 2 | **Reminder time selection** | Bộ chọn giờ học hàng ngày (ví dụ: `20:00`) để gửi nhắc nhở. |
| 3 | **Reminder type** | Lựa chọn các kênh nhận thông báo: Email, Trình duyệt (Push notification) hoặc cả hai. |
| 4 | **Custom reminder message** | Ô nhập thông điệp nhắc nhở tự soạn thảo để tăng động lực cá nhân hóa. |
| 5 | **Reminder frequency** | Tùy chọn tần suất gửi nhắc nhở: Hàng ngày (Daily) hoặc Hàng tuần (Weekly). |
| 6 | **Reminder for specific tasks** | Bật/tắt nhắc nhở khi đến giờ các nhiệm vụ tự học tự chọn trong ngày. |
| 7 | **Reminder for reviews due** | Bật/tắt nhắc nhở khi có từ vựng hoặc ngữ pháp đến kỳ hạn ôn tập (Spaced Repetition due). |
| 8 | **Reminder for tests** | Bật/tắt thông báo nhắc nhở làm các đề thi thử TOEIC theo kế hoạch. |
| 9 | **Reminder for streak maintenance** | Cảnh báo đặc biệt vào buổi tối (ví dụ: 20h) nếu học viên chưa hoàn thành mục tiêu ngày để tránh mất chuỗi học. |
| 10 | **Snooze option** | Nút hoãn thông báo nhanh (Snooze) thêm 10, 15, hoặc 30 phút nếu học viên đang bận học việc khác. |
| 11 | **Disable reminders** | Nút chuyển đổi Master Switch để bật/tắt toàn bộ hệ thống nhắc nhở nhanh chóng. |

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Sẽ Thay Đổi

### 3.1. Cơ Sở Dữ Liệu (`apps/api/prisma`)

#### [MODIFY] [schema.prisma](file:///d:/GITHUB/TOEIC-AI/apps/api/prisma/schema.prisma)
1. Thêm model `StudyReminderSetting`:
   ```prisma
   model StudyReminderSetting {
     id                Int      @id @default(autoincrement())
     userId            Int      @unique @map("user_id")
     enabled           Boolean  @default(true)
     reminderTime      String   @default("08:00") @db.VarChar(5) // Định dạng "HH:MM"
     reminderType      String   @default("push") @db.VarChar(20)  // "push", "email", "both"
     customMessage     String   @default("Đã đến giờ học TOEIC rồi, hãy cùng vào học nhé!") @db.VarChar(255)
     frequency         String   @default("daily") @db.VarChar(20) // "daily", "weekly"
     tasksEnabled      Boolean  @default(true)                    // Nhắc nhở nhiệm vụ tự chọn
     reviewsEnabled    Boolean  @default(true)                    // Nhắc nhở ôn tập đến hạn
     testsEnabled      Boolean  @default(true)                    // Nhắc nhở kiểm tra
     streakEnabled     Boolean  @default(true)                    // Nhắc nhở giữ chuỗi
     snoozeMinutes     Int      @default(15)                      // Số phút hoãn mặc định
     createdAt         DateTime @default(now()) @map("created_at") @db.Timestamp(6)
     updatedAt         DateTime @default(now()) @updatedAt @map("updated_at") @db.Timestamp(6)

     user              User     @relation(fields: [userId], references: [id], onDelete: Cascade)

     @@map("study_reminder_settings")
   }
   ```
2. Thêm quan hệ 1-1 `reminderSetting StudyReminderSetting?` vào model `User`.

### 3.2. Backend API (`apps/api`)

#### [NEW] [reminder.service.ts](file:///d:/GITHUB/TOEIC-AI/apps/api/src/dashboard/reminder.service.ts)
Lớp quản lý cài đặt nhắc nhở học tập:
- `getSettings(userId)`: Lấy cấu hình nhắc nhở của người dùng. Tự động khởi tạo bản ghi mặc định nếu chưa tồn tại.
- `updateSettings(userId, dto)`: Cập nhật các trường cấu hình.
- `snoozeReminder(userId, minutes)`: Trả về thời gian nhắc nhở tiếp theo sau khi hoãn (snooze).

#### [NEW] [reminder.controller.ts](file:///d:/GITHUB/TOEIC-AI/apps/api/src/dashboard/reminder.controller.ts)
Expose các route RESTful:
- `GET /dashboard/reminder` -> Lấy cấu hình.
- `PUT /dashboard/reminder` -> Cập nhật cấu hình.
- `POST /dashboard/reminder/snooze` -> Trực quan hóa hành vi hoãn báo thức học tập.
- `POST /dashboard/reminder/test` -> Trực tiếp gửi giả lập thông báo thử nghiệm về trình duyệt để kiểm tra tức thời.

### 3.3. Frontend (`apps/web`)

#### [NEW] [page.tsx](file:///d:/GITHUB/TOEIC-AI/apps/web/app/dashboard/reminders/page.tsx)
Xây dựng giao diện cấu hình Nhắc nhở:
- **Master Toggle**: Bật/tắt nhanh toàn bộ nhắc nhở.
- **Thời gian & Tần suất**: Ô chọn giờ học, tần suất (Hàng ngày / Hàng tuần).
- **Hình thức nhận tin**: Lựa chọn Push Notification / Email / Cả hai.
- **Thông điệp tùy chọn**: Ô văn bản cho học viên tùy chỉnh câu chữ nhắc nhở.
- **Tùy chọn Hoãn học (Snooze)**: Thiết lập số phút hoãn báo thức học tập.
- **Sự kiện áp dụng (Cài đặt chuyên sâu)**: Cung cấp các nút switch bật/tắt nhắc nhở cho từng sự kiện:
  1. Nhiệm vụ tự học
  2. Từ vựng & Ngữ pháp cần ôn tập
  3. Lịch thi thử TOEIC
  4. Cảnh báo duy trì chuỗi
- **Nút "Gửi thử thông báo"**: Nhấp vào sẽ hiển thị trực tiếp một Popup/Toast giả lập nội dung nhắc nhở ngay trên màn hình.
