# Kế Hoạch Triển Khai & Kiểm Thử: 6.4. Grammar Reference (Tài Liệu Tham Khảo Ngữ Pháp)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Tra Cứu & Tham Khảo Ngữ Pháp Chuyên Sâu (Grammar Reference / Grammar Handbook) phục vụ ôn luyện TOEIC 900+.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu, typography, khoảng cách (spacing), layout và card style hiện có của website mà không làm xáo trộn bất kỳ thành phần nào.

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Backend (`apps/api`)
- `apps/api/src/grammar/grammar.service.ts`:
  - `getReferenceRules(userId, search, category)`: Cung cấp chỉ mục tra cứu quy tắc ngữ pháp.
  - `getReferenceRuleDetail(id)`: Trả về dữ liệu chi tiết quy tắc bao gồm bảng tra cứu nhanh, công thức, ví dụ, ngoại lệ, lỗi sai và mẹo làm bài Part 5 & 6.
- `apps/api/src/grammar/grammar.controller.ts`:
  - `GET /grammar/reference`
  - `GET /grammar/reference/:id`

### Frontend (`apps/web`)
- `apps/web/types/grammar.ts`:
  - Khai báo interfaces: `GrammarReferenceRuleSummary`, `GrammarReferenceDetail`.
- `apps/web/services/grammar.ts`:
  - Khai báo API client: `getGrammarReferenceRules()`, `getGrammarReferenceDetail()`.
- `apps/web/app/dashboard/grammar/reference/page.tsx`:
  - Trang tra cứu toàn diện gồm:
    - Tìm kiếm tức thì theo từ khóa.
    - Bộ lọc danh mục (Các thì, Từ loại & Giới từ, Mệnh đề & Đảo ngữ, Cấu trúc đặc biệt).
    - Bộ lọc quy tắc đã lưu ⭐ (Bookmarked).
    - Khối xem chi tiết với cấu trúc trọng tâm, giải thích, bảng cheat sheet, ví dụ có phân tích, cảnh báo ngoại lệ ⚠️, so sánh lỗi thường gặp ❌ vs ✓, mẹo làm bài TOEIC 🎯.
    - Nút In / Xuất PDF 🖨️ hỗ trợ chuẩn in ấn `@media print`.
- `apps/web/app/dashboard/grammar/page.tsx`:
  - Bổ sung nút liên kết nhanh "📖 Tra cứu ngữ pháp".

## 4. Kết Quả Kiểm Thử (Verification)
1. **Kiểm thử biên dịch TypeScript**:
   - `apps/api`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
   - `apps/web`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
2. **Kiểm thử tính năng tra cứu**:
   - Tìm kiếm quy tắc theo từ khóa, lọc theo danh mục hoạt động mượt mà.
   - Hiển thị đầy đủ bảng tra cứu nhanh, ví dụ, ngoại lệ và lỗi thường gặp.
   - Lưu yêu thích ⭐ đồng bộ tức thời với `localStorage`.
   - Chế độ in ấn (Print-friendly view) hoạt động tốt.
3. **Bảo toàn thiết kế**: Giữ nguyên 100% style dark mode và component hệ thống hiện có.
