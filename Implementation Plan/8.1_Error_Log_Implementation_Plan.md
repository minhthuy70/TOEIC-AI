# Kế Hoạch Triển Khai & Kiểm Thử: 8.1. Error Log (Nhật Ký Lỗi / Sổ Tay Lỗi)

## 1. Tổng Quan Mục Tiêu
Triển khai hệ thống Quản lý và Khắc phục Câu Sai (Error Log / Mistakes Notebook) toàn diện cho nền tảng TOEIC-AI.
> [!IMPORTANT]
> **Cam kết giữ nguyên 100% design hiện tại**: Tái sử dụng chính xác hệ thống component, bảng màu dark theme, typography, khoảng cách (spacing), layout, modals, dropdowns và card style hiện có của website mà không làm xáo trộn bất kỳ thành phần nào.

## 3. Kiến Trúc Kỹ Thuật & Tệp Tin Đã Triển Khai

### Backend (`apps/api`)
- `apps/api/src/error-tracking/error-tracking.service.ts`:
  - Quản lý bảng `error_logs`, xử lý lọc đa điều kiện, sắp xếp, tính toán thống kê và cập nhật tần suất lỗi.
- `apps/api/src/error-tracking/error-tracking.controller.ts`:
  - Cung cấp API `GET /error-log`, `GET /error-log/:id`, `POST /error-log`, `PATCH /error-log/:id/status`, `PATCH /error-log/:id/note`, `DELETE /error-log/:id`.
- `apps/api/src/error-tracking/error-tracking.module.ts`:
  - Khởi tạo module và liên kết Prisma.
- `apps/api/src/app.module.ts`:
  - Đăng ký `ErrorTrackingModule`.

### Frontend (`apps/web`)
- `apps/web/services/error-tracking.ts`:
  - Các hàm API client và kiểu dữ liệu `ErrorLogItem`, `ErrorLogSummaryStats`, `ErrorLogFilterParams`.
- `apps/web/app/dashboard/error-log/page.tsx`:
  - Giao diện Sổ Tay Lỗi toàn diện với 4 thẻ thống kê, thanh tìm kiếm & bộ lọc 5 tiêu chí, danh sách thẻ câu sai, modal chi tiết và modal xác nhận xóa.
- `apps/web/app/dashboard/layout.tsx`:
  - Tích hợp mục "📓 Sổ tay lỗi" vào menu chính bên trái `NAV_MAIN`.

## 4. Kết Quả Kiểm Thử (Verification)
1. **Kiểm thử biên dịch TypeScript**:
   - `apps/api`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
   - `apps/web`: `npx tsc --noEmit` -> Mã thoát: `0` (Không lỗi).
2. **Kiểm thử chức năng**:
   - Tải danh sách câu sai mượt mà, lọc theo loại lỗi / Part / ngày / trạng thái chính xác.
   - Sắp xếp theo tần suất và ngày hoạt động tốt.
   - Xem chi tiết câu hỏi, đoạn văn, audio, hình ảnh và giải thích rõ ràng.
   - Thêm/sửa ghi chú cá nhân, chuyển đổi trạng thái và xóa bản ghi hoạt động chuẩn xác.
